# US-POMO-004: Task Linking, Automatic Completion, And Stopwatch

## Target Behavior

Learners can optionally link an owned Todo or Kanban card before starting Work,
automatically transition when the visible timer reaches zero, receive a browser
alert, and use a transient stopwatch with laps.

## Non-Goals

- Server background scheduling, persisted stopwatch laps, and a session-history UI.
