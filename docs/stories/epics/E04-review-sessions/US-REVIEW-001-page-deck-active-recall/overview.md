# Overview

## Current Behavior

Learners can view synchronized Page Deck cards but cannot study or rate them.

## Target Behavior

Learners complete a Page Deck Active Recall session using Normal or Shuffle
order, card reveal, TTS, mouse or keyboard ratings, and an immediate summary.
Ratings are recorded without changing scheduling.

## Affected Users

- Authenticated learners studying a focused vocabulary page.

## Affected Product Docs

- `docs/product/flashcards.md`

## Non-Goals

- All Words sessions, SM-2 changes, daily limits, settings, dashboard, or
  durable session history.
