# Overview

## Dependency

Starts only after `US-TODO-003` is implemented and reviewed.

## Target Behavior

The shared Todo detail panel offers exactly Daily, Weekdays, Weekly, Monthly,
and Yearly repeat choices. Completing a recurring occurrence preserves it and
atomically creates exactly one next incomplete occurrence with the approved
copied fields and clamped date rules.

Reopening a completed source deletes its unchanged autogenerated next
occurrence. If that child has any user-authored mutation, the child remains,
the source reopens, and the API returns the approved warning. Deleting one
occurrence never cascades.

## Required Boundaries

- Owner-scoped recurrence read and mutation.
- Unique source-to-generated-child lineage and one transaction per lifecycle
  mutation.
- Explicit pristine state instead of timestamp or partial field comparison.
- Domain table tests for weekdays, month ends, and leap years.
- Detail-panel UI and E2E proof in the same story as schema/API behavior.

## Non-Goals

- Custom recurrence.
- Editing an entire series.
- Cascading future deletion.
- Reminder delivery; `US-TODO-005` extends the copied fields after this story.
