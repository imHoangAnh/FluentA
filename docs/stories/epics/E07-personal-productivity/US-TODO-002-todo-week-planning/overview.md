# Overview

## Current Behavior

Todo supports a single-day view and the API already supports inclusive date
range listing plus field-scoped date and sort-order updates.

## Target Behavior

Desktop users can switch to a Monday-Sunday Week view, navigate between weeks,
reorder tasks within a day, and move tasks between days using drag-and-drop.
The resulting order and dates persist.

## Non-Goals

- Mobile drag-and-drop.
- New backend batch endpoint.
- Dashboard aggregation.
- Scheduled Todo jobs.
