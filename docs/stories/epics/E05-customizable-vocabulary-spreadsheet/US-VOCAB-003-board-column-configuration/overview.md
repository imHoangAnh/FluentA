# Overview

## Current Behavior

Vocabulary words have fixed fields. Optional columns are always visible, and
boards cannot define additional fields.

## Target Behavior

Learners can configure board-wide text and number custom columns, privately
toggle optional and custom column visibility per board, edit custom values on
every page, and permanently delete custom columns and their values.

## Non-Goals

- Spreadsheet autosave and keyboard navigation.
- Language-adaptive labels.
- Custom values in flashcard review content.
- Restoring deleted custom columns.
