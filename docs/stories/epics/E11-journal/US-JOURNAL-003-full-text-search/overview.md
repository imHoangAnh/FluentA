# Overview

## Current Behavior

Journal entries are listed newest first, but learners cannot search their
plain-text content.

## Target Behavior

Authenticated learners can search their own active Journal entries from the
Journal list. Results include a contextual plain-text snippet with every
matched query occurrence highlighted.

## Affected Users

- Authenticated FluentA learners.

## Affected Product Docs

- `docs/product/journal.md`

## Non-Goals

- Search by title, learning date, or formatting markup.
- Search ranking or pagination.
- Calendar indicators or date-based open-or-create behavior.
